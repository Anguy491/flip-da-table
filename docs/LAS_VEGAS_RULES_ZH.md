# 《拉斯维加斯》基础版规则

> 文档状态：Flip Da Table 数字版第一阶段规则定稿  
> 版本口径：以 2019 年《Las Vegas Royale》的 **Las Vegas 基础／教学模式**为基础，并采用本文明确列出的平台化调整  
> 第一阶段不包含：双人模式、观战、行动倒计时、多场系列赛、赌场技能板、技能触发、额外黑骰、灰色空白骰及技能专用标记

## 1. 游戏概览

- **人数：**3–10 个座位，至少 1 名真人玩家，其余座位可由机器人补足
- **游戏时长：**约 45–60 分钟
- **完整对局：**固定 3 个赌场大轮
- **目标：**把自己的骰子派往 1–6 号赌场，争夺每家赌场公开展示的奖金。3 个大轮结束后，总资产最高的玩家获胜。

平台上的一场对局始终由这 3 个大轮组成，不设置额外的系列赛局数。

游戏的关键风险来自“同点淘汰”：同一家赌场中，只要两名或更多玩家的最终影响力相同，这些玩家在该赌场的骰子便全部失效。因此，争第一可能让双方一起出局，反而便宜排名更低的玩家。

## 2. 第一阶段使用的游戏元素

### 每位玩家

- 7 颗普通骰
- 1 颗同色大骰（Biggy）
- 第 1 大轮开始时获得 2 枚筹码；第 2、3 大轮开始时再各获得 2 枚，未使用的筹码会保留

大骰在投掷和放置时只是一颗骰子；结算赌场影响力时，大骰按 **2 点影响力**计算，普通骰按 **1 点影响力**计算。

### 公共元素

- 6 家赌场，编号为 1–6，分别对应骰子的六种点数
- 90 张金钱牌：

| 面值 | 数量 |
| --- | ---: |
| $30,000 | 11 |
| $40,000 | 11 |
| $50,000 | 13 |
| $60,000 | 15 |
| $70,000 | 13 |
| $80,000 | 11 |
| $90,000 | 9 |
| $100,000 | 7 |

## 3. 开局与每个大轮的奖金设置

1. 洗混金钱牌，形成牌面朝下的牌堆。
2. 连续抽出 12 张牌，按抽取顺序组成 6 对；每对固定包含 2 张牌。
3. 对 6 对奖金进行排序：
   - 两张牌总额最高的一对分配给 6 号赌场；
   - 第二高分配给 5 号赌场；
   - 依次类推，总额最低的一对分配给 1 号赌场；
   - 若两对总额相同，则其中单张最高面值更高的一对分配给编号更高的赌场；
   - 若总额和单张最高面值都相同，两对实际等价，先后顺序不影响游戏。
4. 每家赌场的两张金钱牌均正面公开。
5. 每位玩家拿取自己的 7 颗普通骰、1 颗大骰和本轮新增的 2 枚筹码。

第一大轮的先手由服务端安全随机选出。这是 Flip Da Table 数字版相对于实体规则的固定平台化调整。

## 4. 玩家行动

玩家按固定顺序轮流行动。轮到玩家时：

1. 主动点击“掷骰”，一次投掷自己当前尚未放入赌场的 **全部骰子**。
2. 查看结果后，从本次掷出的点数中选择 **一种点数**。
3. 把所有显示该点数的骰子一起放到对应编号的赌场。
4. 其余点数的骰子收回，留待自己的下一次行动继续投掷。

例如：玩家掷出四颗 3 和一颗 5，可以选择把四颗 3 全部放进 3 号赌场，也可以把一颗 5 放进 5 号赌场；不能只放一部分 3。

补充约束：

- 大骰与普通骰遵循相同的选择规则。若所选点数同时出现在大骰和普通骰上，这些同点数骰子必须全部放置。
- 不消耗筹码时，玩家不能主动放弃行动，也不能重新投掷。
- 已经没有未放置骰子的玩家会被跳过。
- 若大轮末段只剩一名玩家仍有骰子，该玩家会在其他人均被跳过后继续行动，直到放完所有骰子。

### 使用筹码跳过

玩家看到本次投掷结果后，可以支付 1 枚筹码跳过此次行动：

- 本次不向任何赌场放置骰子；
- 所有刚投出的骰子回到玩家的未放置骰池；
- 轮到下一位玩家；
- 下次轮到自己时，再重新投掷这些骰子。

每次行动最多使用 1 枚筹码。未使用的筹码会跨大轮保留，并在游戏结束时计入资产。

## 5. 大轮结束与赌场结算

当所有玩家都放完自己的全部骰子后，本大轮结束，依次结算 6 家赌场。

### 第一步：计算影响力

分别计算每名玩家在该赌场的影响力：

- 每颗普通骰 = 1
- 每颗大骰 = 2

### 第二步：消除所有同点

检查该赌场内所有玩家的影响力。任意两名或更多玩家影响力相同，这一组玩家在该赌场全部失去资格，他们的骰子全部移除。

同点消除不是只检查第一名，而是检查 **所有名次的所有同点组**。

示例：影响力为 `5 / 3 / 3 / 1` 时，两名影响力为 3 的玩家一起出局，剩余玩家按 `5 / 1` 排名。若影响力为 `2 / 2 / 1 / 1`，四名玩家全部出局。

### 第三步：发放奖金

在消除同点后：

1. 影响力最高的合格玩家获得赌场两张金钱牌中面值较高的一张，即头奖。
2. 影响力第二高的合格玩家获得另一张金钱牌。
3. 其他玩家没有奖金。
4. 若只有一名合格玩家，他只获得头奖；若没有合格玩家，则两张牌均无人获得。
5. 所有无人获得的金钱牌牌面朝下放到金钱牌堆底部。

即使两张奖金牌面值相同，第一名取得的仍视为“头奖牌”，第二名取得另一张。

### 信息公开与资产展示

- 自己始终可以查看自己的金钱牌面值、现金总额、筹码和总资产。
- 对手默认只能看到其金钱牌张数、筹码数、剩余骰子和各赌场影响力，不能看到其现金总额或各张金钱牌面值。
- 赌场奖金、本次掷骰结果、已放置骰子和赌场影响力属于公开信息。
- 赌场结算时会临时展示本次具体奖金金额；结算后的持久记录只保留“赢得某赌场头奖／次奖”，不持续公开金额。
- 游戏结束后，公开所有玩家的最终总资产、破同分所用数量和最终排名。

玩家可在对局中随时选择“公开总资产”，也可随时收回。公开时只向全桌展示当前总资产，即金钱牌总额加剩余筹码估值，不展示各张牌的面值明细。此功能属于平台展示能力，不是规则行动：不占用回合、不消耗筹码，也不会改变游戏状态或结果。

## 6. 进入下一大轮

结算完成后：

1. 所有玩家收回自己的 8 颗骰子。
2. 重新抽取 12 张金钱牌，组成并排序 6 对新奖金。
3. 每名玩家再获得 2 枚筹码，未使用筹码继续保留。
4. 从 6 号赌场开始，按 6、5、4、3、2、1 的顺序向下查找；第一个产生头奖赢家的赌场，其头奖赢家成为下一大轮先手。若本大轮六家赌场都没有产生任何赢家，则从本大轮先手的下一座位开始下一大轮。

## 7. 游戏结束与胜负

第 3 大轮结算完成后，游戏立即结束。

1. 每枚剩余筹码按 **$10,000** 计入资产。
2. 金钱牌总额与筹码价值之和最高者获胜。
3. 若总资产并列，则比较玩家持有的“金钱牌张数 + 筹码枚数”，数量较多者获胜。
4. 若仍然相同，则并列获胜。

## 8. 第一阶段明确不包含的内容

以下均属于《Las Vegas Royale》进阶模式，不进入第一阶段：

- 每个大轮随机抽取赌场技能板；
- 在 1、2、3 号赌场放骰后触发额外效果；
- Jackpot、Lucky Punch、Prime Time、High Five、Bad Luck 等技能；
- 技能使用的黑色额外骰、灰色空白骰、奖励银行及专用标记；
- 任何由技能造成的移骰、封锁赌场、额外奖金或特殊结算。

大骰和跳过筹码是 Royale 基础模式的正式规则，**不属于扩展技能**。

此外，第一阶段支持 3–10 个总座位且至少包含 1 名真人玩家，明确不提供：

- 双人模式及任何中立骰规则；
- 观战；
- 行动倒计时；
- 多场系列赛。

### 标准机器人

- 房主可在大厅添加机器人，机器人使用 `Bot 1`、`Bot 2` 等固定显示名；一场对局仍不得超过 10 个座位。
- 机器人完全由服务端执行，客户端不能代替机器人提交动作。
- 机器人只读取公开奖金、公开放置、剩余骰子、筹码和本次公开掷骰，不读取任何对手隐藏的金钱牌或资产总额。
- 机器人会比较各合法点数的暂定奖金、同点淘汰、安全差、骰子消耗和大骰保留价值；只有所有落点都会零收益同点出局时，才会考虑支付筹码跳过。
- 掷骰与选择会分别持久化和广播，默认间隔约 800ms，方便真人看清过程。这个间隔只是展示节奏，不是行动倒计时。

## 9. 与 2012 经典原版的区别

网上大量中文介绍采用 2012 年原版规则，不能直接与本稿混用。

| 项目 | 2012 经典原版 | 本稿：Flip Da Table 基础版 |
| --- | --- | --- |
| 大轮数 | 4 | 3 |
| 玩家骰子 | 8 颗普通骰 | 7 颗普通骰 + 1 颗大骰 |
| 筹码 | 无 | 每轮新增 2 枚，可跳过；剩余每枚值 $10,000 |
| 赌场奖金 | 每家持续翻牌，直到总额至少 $50,000 | 每家固定 2 张，按牌对总额分配给 1–6 号赌场 |
| 金钱牌 | 54 张，$10,000–$90,000 | 90 张，$30,000–$100,000 |
| 第一大轮先手 | 由规则指定的玩家 | 服务端安全随机 |
| 下一轮先手 | 上一先手左侧玩家 | 上轮最高编号产生头奖赢家的赌场之头奖赢家；若全轮无人获胜，则为上轮先手的下一座位 |
| 双人模式 | 包含双人变体 | 不支持，数字版为 3–10 个座位且至少 1 名真人 |

## 10. Flip Da Table 数字版固定口径

以下边界已确定，不再作为待复核项：

1. 第一阶段采用 Royale 基础模式，一场对局固定包含 3 个大轮。
2. 房间允许 3–10 个总座位且必须至少有 1 名真人；2 个座位、11 个座位或全机器人配置均不合法。
3. 第一大轮由服务端安全随机选择先手；后续大轮按第 6 节确定先手。
4. 对手资产默认隐藏；玩家主动公开或收回总资产仅是平台展示功能。
5. 不支持双人中立骰、观战、行动倒计时或多场系列赛。
